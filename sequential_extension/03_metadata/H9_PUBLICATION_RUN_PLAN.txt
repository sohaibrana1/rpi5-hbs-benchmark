MEASUREMENT RULES
-----------------
1. One independent warm-up key per run.
2. 100 warm-up signatures.
3. Warm-up signatures are excluded from publication data.
4. A fresh independent measurement key is then generated.
5. Measurement key must begin at index 0.
6. The same measurement key is advanced contiguously through the
   complete configured run.
7. No index skipping.
8. No key reset during a run.
9. Signing latency uses CLOCK_MONOTONIC_RAW.
10. Only the signing call is inside sign_ns timing.
11. Verification occurs outside sign_ns timing.
12. Every measured signature must verify.
13. Verification failure invalidates the run.
14. Every row records index-before and index-after.
15. Message length is fixed at 32 bytes.
16. CPU affinity for publication runs: CPU 3.
17. CPU governor requirement: performance.
18. Failed or interrupted runs are preserved, never silently deleted or
    pooled with valid data.
