# Licensing and Attribution

This reproducibility repository contains source code and research
artifacts with different licensing and attribution requirements.

## Stateful XMSS/XMSS-MT source

The source trees under:

- `source_stateful/w4/`
- `source_stateful/w16/`
- `source_stateful/w256/`
- `source_stateful/wots_experimental/`

retain their original CC0 1.0 Universal license.

The complete original license text is included as `LICENSE` in each
source tree.

No original license file has been removed or replaced.

## SLH-DSA source

`source_slhdsa/upstream_snapshot/`

is a frozen snapshot of:

`pq-code-package/slhdsa-c`

Upstream repository:

https://github.com/pq-code-package/slhdsa-c

Frozen Git commit:

`174c02e42257f95c210963272877c49dbb50070f`

The original upstream `LICENSE` file is preserved in the snapshot.

The upstream project contains licensing notices including ISC and MIT
terms. Those original notices govern the corresponding upstream code.

The upstream implementation is not claimed as original work by
Sohaib Rana.

## Research artifacts
